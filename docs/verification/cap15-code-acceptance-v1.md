# CAP-15: original advice policy crosswalk, code acceptance

The owner-selected four phases are active at the shared writer/reviewer boundary
for substantive catalog advice: opening, data core, synthesis, closure. Price,
clarification, social/no-match and the opening-carousel contract stay short or
retain their own format. The four-phase rule is a model policy plus independent
semantic review, not a claim every live model answer follows it. No extra model
calls, delayed review or quota changes were added.

Original STANDARD_ADVISORY maps to evidence_and_unknowns: actual facts, supported
tradeoffs, missing evidence and useful next step. VERIFIED_CLOSER's useful intent
maps to explicit_concern_and_evidenced_options, only for an explicit negotiation,
objection or current stated hesitation. It does not prove stock, provenance,
competitive superiority, a discount or power to act. FRAUD_PROTECT's safe scope
maps to scope_and_clarify: absence of results is not fraud, nonexistence or global
supply evidence. A missing model stays unverified; no fabricated debunking or
forced retention pivot. price inquiries map to listed_price_only.

Hidden persona/wealth/gender profiling, fake urgency/social proof, global stock,
supremacy and execution claims are deliberately excluded, not silently treated
as restored capabilities. Original prompt symbols/methods remain preserved.
An AST audit guards their reads as confined to retained unreviewed bodies.
Current strategies are task metadata, never product proof or customer profile.
Independent review rejects unsupported selling claims and pressure. Existing
exact-card claim/sanitizer boundaries remain authoritative. Tiny no-match
prompts remain unchanged to preserve their compact request budget.
