# Legacy ecosystem read-only boundary

The original ecosystem entrypoint now bridges into the existing shared reviewed
setup planner, staged component searches, literal ShoppingBrief filters, current
SQL publication/recheck and shared model writer/reviewer. Ordinary HTTP routing
is unchanged. The original unreviewed handler remains under an explicitly legacy
name for source continuity, not selected by the entrypoint.

A separate model extraction and independent review preserve explicit current
customer budget, currency, features and exclusions. Literal grounding rejects
invented spans rather than broadening the search. An unresolved budget clarifies.
The old intent_payload budget is not evidence. No premium/best-rated query suffix,
arbitrary three-item fallback, perfect-compatibility claim or unsourced category
product list is used. Shared setup plan still caps at3components and5cards; it is
not proof of a complete system. Shared current-row budget/constraint and postcopy
SQL gate stay authoritative. Component identity/scope is separately reviewed.

This bridge deliberately does not read legacy inferred DNA/history, persist
preferences, save conversation turns, publish bus messages or mutate carts.
Request-local shared context is explicitly empty and reset afterward to prevent
unrelated inherited context affecting the setup. Only the injected reviewed
inference adapter is used; none is created on import. Whole bridge45second cap,
shared stage/model caps, fail-closed output and cancellation propagation remain.

Real migrated disposablePG19 tests enter the original handler and control actual
inference/search transport. Cases: success, currentprice changed during copy,
demo-only rows, rejectedplan, invented/omittedbudget, numericreview rejection,
outofstock, overbudget, writeroutage and cancellation. No bus writes or memory
turn saves. Real model semantic entailment, multilingual extraction/quality,
physical fit/completeness and ownerdeployment remain unverified. No provider
calls, owner actions, canonicalliveflag promotion or heldPR change.
