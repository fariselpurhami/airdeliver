# Explicit advisory tasks on ordinary routing

The strict ordinary router now accepts price_inquiry, negotiation and objection
as distinct read-only shopping tasks, matching existing retained classifier
categories. Task/question remain context, not proof of a concern, discount,
competitor policy, finances or product fact. Shared writer policy distinguishes
listed price, an unapproved concession request and explicit product hesitation.
Both staged and direct catalog paths carry exact task/question to shared copy.
No added model call, cart action, quota policy or reduced review.

Six migrated PostgreSQL cases use actual strict router parsing and both search
entrypoints, then assert fresh cards, exact task/question evidence, no action and
three controlled model calls (router/writer/review). They do not prove live model
classification in any language or full original intent-taxonomy acceptance.
