# Home ordering layer and continuous atmosphere

Root cause found in source: AppShell hosts a global AIChatOverlay; home entry sets global isOverlayVisible and renders a second page-local AIChatOverlay under an isolated landing container. Products also renders a page-local copy. Each instance mounts session/socket/scroll effects, even while its markup is closed. Header and overlay previously both usedz50, with home introducing another stacking context. Duplicate work and stacking are demonstrated defects; their exact contribution to iPhone frame latency is not measured.

A shell ownership context now lets existing page-local entry components remain in place but suppresses their live session under AppShell. Standalone overlay use remains available outside that host. One global session/scroll lock/socket lifecycle is retained. Site header/footer/chatbot are hidden and inert while ordering is open; main is inert, aria-hidden and visibility-hidden, preserving page state and scroll position without rendering it behind chat. Overlay has a dedicated1000 layer and an opaque mobile backdrop, desktop blur retained. Home canvas stops and cleans up its frame loop while ordering is open, restarts on close. Home store subscriptions narrowed to relevant selectors. Existing home sections, cards, checkout, page entry points and product logic remain.

Atmosphere CSS had full-page radial layers tiled at1600px by default. A tile restart can create the reported horizontal color seam. Full-page gradients now do not repeat, star pattern still repeats, teal/purple intensity reduced. How-it-works cyan/purple150px glows become restrained80px glows. Accent icons/lines retained. No screenshot-based claim that this is the only possible Safari compositor artifact.
