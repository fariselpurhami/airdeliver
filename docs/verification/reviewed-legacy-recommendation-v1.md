# Legacy recommendation copy, explicit-card path

Complete caller-supplied active/inventory/price/currency dictionaries now take a
model-authored structured recommendation path. Intro and reasons survive only
with valid card IDs, exact claims, per-product numeric/identity checks, fixture
policy and full independent grounding review. Rejection/provider/deadline failure
withholds the selection rather than replacing prose with a positive template.
Current orchestrator preserves explicit evidence through local ranking and does
not repopulate IDs after reviewed rejection. No mutation or provider-policy change.

Incomplete historical dictionaries retain the existing deterministic factual
compatibility adapter; no active-stock or fresh-SQL claim is invented for them.
This remaining distinction is explicit, not universal model-prose completion.
Caller supplies evidence freshness; adapter freezes it and rejects mutations
while awaiting review, but does not itself query SQL. No claim of merchant stock.

Sixteen tests cover actual strict adapter schemas, preserved prose, independent
rejection, injected IDs/fields/numbers, wrong-product claims, duplicate IDs,
fixture policy, stale mutation, cancel/outage and actual orchestration. Existing
legacy compatibility and grounding tests retained. No provider/owner execution,
Granite change or live-model semantic acceptance. CAP54/55 narrowed, not closed.
