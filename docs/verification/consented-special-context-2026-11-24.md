# Consented preferences in special paths

Research and setup receive canonical consented shopping preferences as a separate optional-hints field. Current customer text wins. Hints do not become hard features, budget, recipient, source facts or compatibility evidence. They are not appended to external search queries. Setup hard feature spans must still be found in actual customer turns, not saved hint text. Image copy already uses the shared catalog response context.

The existing feature-off default, owner-bound SQL recall, expiry, revocation recheck before publication and deferred history rules remain unchanged. Six new actual HTTP/PostgreSQL/Redis cases cover setup/research, owner mismatch and revocation while the model runs. The personalized result is withheld and not saved to session history after revocation. Model transport and source search are controlled in tests; no provider calls or live interpretation claim.
