# Current AI profile registry, first additive slice

`AI_PROFILE=current-v1` is the default. It declares existing Groq text brain/reflex/support and image-understanding roles, local GTE1536/SigLIP1152 retrieval identities and ElevenLabs conversational voice. Existing main model env overrides are preserved; GROQ_SUPPORT_MODEL adds a central override for the formerly hardcoded support model. Unsupported profile/provider/capability/model identifier and index-incompatible retrieval substitutions fail explicitly, no silent provider fallback. Missing provider keys retain existing runtime handling rather than making optional services mandatory.

Factories wrap the existing code, not replace prompts or command execution: FreeLLMService and NeuralCoreService create Groq clients through GroqAdapter; ModelRegistry creates existing local models/processors through LocalRetrievalAdapter; AIVoiceOrchestrator connects its existing ElevenLabs wire flow through ElevenLabsConversationAdapter. Service-owned deadlines/retries/cancellation and current env routing are preserved. VoiceConfig retains current agent/key source. No standalone STT/TTS or PersonaPlex adapter is falsely advertised. No provider call, credential, migration, index recreation or model download.

Only ONE provider profile is registered. This is a real common configuration/factory boundary for current services, NOT proof arbitrary providers are swappable, a hot switch, or a multi-provider fallback system. Additional profiles require registered adapters, compatible capability/output/audio contracts, owner credentials/spend authority, offline and real evaluation. Selecting a profile remains restart-time configuration. Retrieval models are pinned to current index identity/dimensions until a separate migration/reindex plan is approved.

Tests cover default/role overrides, unsupported profile/provider/capability/index changes, real Groq SDK URL+JSON through fake HTTP transport, preserved local factory options, voice connector/error propagation, existing real loopback duplex audio and existing text deadline/grounding cases. Tests do not establish provider equivalence or production quality. All old methods and files remain.
