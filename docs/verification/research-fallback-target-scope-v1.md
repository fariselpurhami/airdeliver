# Source research keeps catalog fallback scope

Informational source lookup remains first and independent of local stock or
shopping hard constraints. If no source is returned and the ordinary chat path
falls back to catalog cards, saved per-target positive/negative constraints now
reach that fallback through the existing reviewed scope handler. A catalog-only
branch avoids recursively launching the same source research again. A blocked
scope clarification survives the no-source wrapper instead of being replaced by
a generic source-empty answer.

Nine of twelve original mounted HTTP/SQL/Redis fallback regressions failed before
the fix. Fifteen cases now cover all three informational tasks, scoped sibling
selection, wrong RAM, writer-time SQL change, unresolved renamed target and source
success with no catalog retrieval.96focused source/advisory/SQL tests pass. This
is controlled inference/lookup boundary evidence, not semantic source entailment,
router accuracy or whole-group completion. No provider or owner-store operation.
